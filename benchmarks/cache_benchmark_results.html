What "how much do I carry" means

Token carry = fraction of per-turn input tokens served from Claude's prompt cache.
In this 20-turn IDE session: BP1 tools (8,000 tok) + BP2 system (3,200 tok) + BP3-HOT loci_context (1,200 tok) = 12,400 tokens stay in extended (1-hr) cache — the "hot teachers" (Arc memory + Codex code blocks with heat ≥ 0.80).

By turn 10, ~61% of every Claude API call's input tokens are served at $0.30/M instead of $3.00/M.
That's a 45% cost reduction on input tokens for the fixed context.
